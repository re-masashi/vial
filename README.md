# Vial

Vial aims to be a concurrent, safe, and performant programming language.

## Features

- Structured concurrency with swappable schedulers
- Generational GC with escape analysis (stack allocation when possible)
- Optional arenas for performance-critical code
- Metaprogramming with comptime, macros, and attributes.
- Zero-to-low-cost abstractions
- No async/await, no "colored function" issues.
- Lightweight green threads
- Feature rich stdlib
- HKTs, GADTs, ADT, higher order functions, traits, etc.
